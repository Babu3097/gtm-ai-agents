# Example task — paid social launch

A walkthrough of one real workflow, with names and figures replaced by placeholders.

1. **Input** — I hand the `ad-creative` skill the business-context file plus the brief: "launch an ad set for [Hero Product], targeting [audience segment]."
2. **Agent runs** — the skill returns a set of headline and body copy variations, built entirely from what's in business-context.md.
3. **My review** — I check each variation against the brand-voice section, cut anything off-tone, and edit the two borderline ones myself.
4. **Ships** — the approved set goes live in Meta Ads Manager.

The same four-step loop runs for every skill in the stack — `pricing` reviewing a bundle, `seo-audit` checking the storefront, `customer-research` digesting reviews — just with a different skill and a different brief each time. Nothing ships without step 3.
